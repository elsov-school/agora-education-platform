# Ágora — Apresentação do Projeto

Apresentação HTML independente da aplicação web e do CRUD em Python.

**Abrir online:** [agora-apresentacao.vercel.app](https://agora-apresentacao.vercel.app).

Edite [index.html](index.html) para trabalhar na **v2**. Ela parte do HTML publicado na Vercel. A [cópia da v1](../agora-html-apresentacao-v1/index.html) guarda a apresentação anterior completa, incluindo imagens e controles.

## Abrir no computador

Abra `index.html` no navegador com um duplo clique. Não é necessário instalar Python, Flask ou pacotes.

## Publicar na Vercel

O projeto **agora-html-apresentacao** usa `agora-html-apresentacao` como **Root Directory**, o preset **Other** e a própria pasta como saída. Não há etapa de build.

Para publicar alterações pela CLI, abra o terminal na pasta principal do repositório:

```bash
vercel link --yes --project agora-html-apresentacao --scope lohans-projects-1668e663
vercel deploy --prod --scope lohans-projects-1668e663
```

A apresentação é publicada separadamente do site `agora-app-html-demo`.
